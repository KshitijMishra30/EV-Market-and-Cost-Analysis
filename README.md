# Indian Electric Vehicle Market & Cost Analysis

## Overview
A Power BI dashboard project exploring India's electric-vehicle market and comparing EV-related cost and range measures with petrol-vehicle equivalents.

## Analysis focus
The project context includes year-wise and state-wise EV registration trends, vehicle-category comparisons, and cost/efficiency measures such as petrol cost per kilometre, petrol range for ₹100, petrol litres for ₹100, and savings per ₹100. Consult the report's visuals and DAX measures for the precise calculations and definitions.

## Tools
Microsoft Power BI Desktop, Power Query, DAX, Data Modeling, Data Visualization.

## Files
- `EV_Market_and_Cost_Analysis.pbix` – Power BI report file.

## How to view
1. Download and install [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
2. Download this repository.
3. Open `EV_Market_and_Cost_Analysis.pbix` in Power BI Desktop.
4. If prompted, update data-source paths or credentials, then refresh the report.

## Data note
The PBIX may depend on external CSV/Excel files or data connections that are not included here. Include only source datasets you are allowed to redistribute. Update local data paths before publishing if needed.
